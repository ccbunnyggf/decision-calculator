# 边界 · 个人消费决策与边界收益计算器

本地 Web App。数据只保存在浏览器 `localStorage`，不需要注册、后端或网络服务。打开后先看到随本地时间切换光线的生活场景；点击“开始探索”进入五个工具入口：个人财务、消费计算、出行比较、方案比较、边界分析。初次打开使用示例数据，请先替换为自己的输入。

## 运行

已附带构建结果。电脑装有 Node.js 24 或更新版本时，在本目录运行：

```powershell
node serve.mjs
```

打开 `http://127.0.0.1:4173/`。退出用 `Ctrl+C`。

若想在同一 Wi-Fi 下的手机浏览器预览，可在电脑上设置 `HOST=0.0.0.0` 后启动，再用电脑的局域网 IP 和端口 `4173` 访问。例如 PowerShell：`$env:HOST='0.0.0.0'; node serve.mjs`。此时静态页面会对局域网开放，个人输入仍保存在访问设备的浏览器里。

修改源码后，安装依赖并重新构建：

```powershell
pnpm install
pnpm test
pnpm build
node serve.mjs
```

此交付已验证静态构建和本地预览。数据保存在当前浏览器的当前源，切换端口或浏览器不会共享数据。

## UI 重构

桌面端采用左侧导航和编号内容区；手机端使用可横向滚动的顶部导航。五个计算页面保留原有输入与公式说明，较少用的参数收在展开区。重要折线图显示全部实际绘制点的 X/Y 值、当前点与边界标记；图下可展开精确数据表。点数多时图表需要横向滚动，为保证相邻标签能读清，图上的横向距离不严格按数值比例；请以坐标标签和数据表读取具体数值。详细改动见 `UI-UX-重构报告.md`。

金额统一为人民币数值；年利率在核心函数中用小数，例如 `0.05` 代表 `5%`。单程通勤时间以分钟填写。缺失的可选费用按 0 处理；必填的持有年数等必须大于 0。负费用、NaN、Infinity 会被拒绝并在页面显示错误。自由现金流与安全垫差额可为负。分母为零时显示 `—`，不输出伪造的无穷值。

## 核心公式与假设

1. **月自由现金流**：税后收入 − 必要支出 − 固定债务 − 固定储蓄/投资 − 已知月度刚性支出。
2. **可自由配置资本**：可支配现金 − 最低安全垫 − 近期已知一次性刚性支出。其他流动资产与家庭支持只记录，不自动折算为现金。
3. **成本分类与基础 TCO**：资产成本是购买价 − 期末残值 + 机会成本；固定持有成本含保险、固定停车、订阅与固定维护；可变使用成本含能源、路桥、按通勤日停车及额外里程变动成本。基础 TCO = 购买价 − 期末残值 + 固定与可变年成本 × 持有年数 + 一次性费用。融资成本单列。
4. **融资成本**：融资方案商品价 − 现金价 + 明示总利息 + 手续费。融资方案商品价 12,000 元、现金价 11,500 元且标称 0 利率时，仍有 500 元隐含价差。若融资方案有补贴，融资成本可以为负。
5. **资金机会成本**：逐月估计商品市值和未还贷款本金，对两者差额中的正值按年机会成本率除以 12 计费，再求和。商品市值在购买价与期末残值之间线性变化，贷款本金按期数线性减少。这是显式近似，不是投资回报预测，也没有预测税收、复利或月内付款时点。维护费用没有再计机会成本。
6. **经济 TCO**：基础 TCO + 融资成本 + 机会成本估算。旧物出售回款只减少初始现金占用，不再从经济 TCO 扣减：继续持有成本已经以旧物当前市值为起点，重复扣除会把同一价值计算两次。
7. **继续持有现有资产**：其“购买价”字段代表今天的市场价值，用于计算未来折旧与机会成本；不会作为今天的现金支出。历史购买价仅展示，不进入未来成本。
   通用消费页也可填写旧物当前市值、未来残值与年继续持有成本，直接查看新购方案相对继续持有的增量成本。
8. **年均/月均/单次成本**：经济 TCO 分别除以实际持有年数、月数、总使用次数。寿命兑现率为实际持有年数除以理论可用寿命。
9. **现金安全性**：净初始支出 = 首付 + 前付手续费 + 一次性费用 − 确认出售旧物回款。全款时首付为现金价。购买后现金 = 当前现金 − 净初始支出；安全垫差额 = 购买后现金 − 最低安全垫。小于 0 表示当前方案资金不足；非负但低于安全垫表示可执行但跌破安全垫。初始资金占用月数 = 净初始支出 ÷ 月自由现金流；经济成本对应自由现金流月数 = 全周期经济 TCO ÷ 月自由现金流。延迟购买的现金预计额另加等待期的月自由现金流，并扣除近期已知刚性支出；假设期间价格、收入和支出不变。
10. **出行时间**：每日用时 = 2 × 单程各时间分项。总节省小时 = (替代方案每日分钟 − 汽车每日分钟) × 年通勤天数 × 持有年数 ÷ 60。每节省 1 小时成本 = 汽车与替代方案的增量经济 TCO ÷ 正的总节省小时。可选的乘车时间可利用比例仅用于“不可自由支配时间差”，不把阅读等主观收益换算成人民币。汽车 TCO 涵盖通勤与非通勤里程，时间收益只涵盖通勤。
11. **时间边界**：最少每日节省分钟 = 增量经济 TCO × 60 ÷ (愿付金额/小时 × 年通勤天数 × 持有年数)。价格边界与年停车费边界通过单调二分法求解。无正的时间收益或搜索范围内无解时显示 `—`。

汽车依赖链是：通勤日数 × 每日往返公里 + 年非通勤公里 = 年总公里；自动能源、每公里路桥与额外里程成本随总公里变化；按通勤日停车费随日数变化，固定年度停车不变。固定能源模式明确保持年金额不变并显示提示。额外里程成本不得包含已由残值、能源或固定维护反映的费用；程序无法从数字识别语义重复，需用户核对。

汽车的年份变化使用至少两个用户残值锚点线性插值；超出范围不给出结果。可选的“额外公里对残值的影响”仅在用户填入参考年公里和每公里残值影响后生效。没有足够锚点的旧数据仅在原持有年限使用手动残值，年份曲线不绘制。通用消费页的年份年均成本曲线仍以当前填写的残值作为固定假设，不用于不同年份的总 TCO 增量结论。

方案比较中的 `analysisHorizonYears` 只是预留输入；当前只有方案持有周期相同才给出总 TCO 增量。未建立周期结束后的替代链，因此不会根据预留周期虚构补足成本。不同周期仍展示各自经济 TCO、年均与月均成本、年均成本变化和逐项主观体验变化。

价格敏感性计算在当前持有年限内保持残值锚点和其他费用不变。融资时保持原首付比例、融资价差、总利息和手续费，贷款本金随价格变化。价格边界只描述在当前输入与每小时支付意愿下使时间收益边界成立的购车价格，不是推荐价格。

体验面板的 1–5 级分别记录舒适、灵活、隐私、疲劳、拥挤、停车麻烦、天气暴露、驾驶压力、可阅读时间与事故风险暴露。各维度方向不同，因此不汇总成分，也不换算为人民币。

## 现实案例核对

| 案例 | 预期 | 验证 |
| --- | --- | --- |
| 月入 20,000，必要支出 8,000，债务 2,000，储蓄 3,000，月刚性支出 1,000 | 月自由现金流 6,000 | 单元测试 |
| 现金价 11,500，24 期总商品价 12,000，0 利率 | 隐含融资价差 500；月供 500 | 单元测试 |
| 相机历史购买价 8,000，今天可卖 6,500 | 继续持有的机会成本基数为 6,500，不是 8,000 | 单元测试 |
| 汽车比地铁 5 年多花 160,000，节省 800 小时 | 每小时 200 | 单元测试 |
| 手机理论寿命 5 年，预计持有 3 年 | 寿命兑现率 60% | 单元测试 |

没有纳入通胀、税收、车辆税费政策、残值概率分布、事故损失、拥堵波动、不同通勤日行程或保险覆盖差异。它们会影响结果，适合在未来以明确情景或概率区间加入。

## V2 数据兼容

保留原 `consumer-boundary-app-v2` localStorage 键。旧方案的 `ownedAlready` 会迁移为 `kind`；旧汽车的年总公里与固定年能源金额保持原计算口径，并提示拆分里程与设置残值锚点。旧 `perKmWear` 作为新版“额外里程变动成本”的单一别名读取，不叠加两次。原值会保存在浏览器中，迁移后继续自动保存。唯一有意的数值变化是旧物出售回款不再从经济 TCO 重复扣除。
